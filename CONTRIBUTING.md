# Contributing

Read `AGENTS.md` and the three mandatory doctrine documents in their prescribed
order before changing architecture, contracts, security, dependencies, artifacts,
training, or implementation.

All work must use a branch and pull request. Run Ruff, Black, strict mypy,
repository validation, pytest with 100% source coverage, package build, and exact
distribution verification. Do not weaken CI, add proprietary-provider
dependencies, commit tokenizer corpora or secrets, or claim unsupported
implementation maturity.
